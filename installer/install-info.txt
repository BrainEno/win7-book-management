欢迎安装 BOOK DESK 简易图书管理系统

这是一个完全离线运行的小型书店进销存软件。

安装程序会自动完成以下事情：
1. 安装程序本体和全部运行依赖，不需要您手工寻找或下载 DLL。
2. 如果电脑没有 .NET Framework 4.8，会使用安装包内置的微软离线安装程序完成安装。
3. 自动创建桌面快捷方式。
4. 第一次启动后会自动出现“新手引导”，一步一步告诉您从哪里开始。

推荐给电脑新手的使用顺序：
图书资料 → 采购入库 → 销售开单 → 单据中心/退货 → 报表导出 → 每日备份

重要：
- 本软件要求 Windows 7 SP1 或更高版本的 Windows。
- 数据全部保存在本机，请定期使用软件内的“备份与恢复”功能。
- 如果安装 .NET Framework 4.8 后系统提示重新启动，请先重启电脑，再打开 BOOK DESK。
