# Win7 实机烟测清单（发布前必须填写）

CI 的 Windows Server 2022 结果不能替代以下验收。记录日期、操作者、系统版本 / 架构、SP1、KB4474419 / KB4490628、内存、CPU、磁盘、DPI、打印机、Office/WPS 版本和安装包 SHA-256。

## 安装与显示

- [ ] 未打 SHA-2 补丁的 Win7 SP1：中文提示，可退出；打补丁重启后可安装。
- [ ] 无 .NET 4.8：离线安装有进度与时间预期；失败显示中文原因和日志目录；3010/1641 不强行启动。
- [ ] 1024×768@100%、1280×1024@100%、1366×768@100%/125%、1920×1080@125%/150%：主窗口、导航、结账 / 复核按钮可达。
- [ ] 缺雅黑 / 宋体回退：无裁字；低配模式关闭动画。

## 业务与数据

- [ ] 新建库、历史样本库迁移、未来版本拒绝写入；迁移失败回滚且快照可恢复。
- [ ] 采购 / 销售 / 双向退货 / 调整：库存与流水一致，金额以分计。
- [ ] 连续两天启动 / 退出产生滚动备份；U 盘第二份存在；拔出 U 盘显示警告；保留数生效。
- [ ] 验证最近备份；损坏备份拒绝；恢复失败自动回滚；恢复后重启。
- [ ] 导出期间界面可响应、可取消；取消不破坏旧文件；销售 / 采购 / 经营月报在 Office 2010、WPS、Office 2003+兼容包打开并打印。
- [ ] 人为 UI 异常显示中文编号，日志有堆栈；诊断 ZIP 不含数据库。
