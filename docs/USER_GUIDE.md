# BOOK DESK 使用手册

## 第一次开店

1. 在“图书资料”新增图书，或点击“批量导入”下载 Excel / CSV 模板。导入前先预览新增 / 更新 / 冲突和错误行；全部通过才会一次性写入，且不会从模板修改库存。书名必填；ISBN 可选，留空可直接保存，ISBN-10 会转为 ISBN-13。若 ISBN 填错，保存时可选择“清空 ISBN 并继续保存”，原始输入会记入备注；系统不会生成假 ISBN，自出版物使用自动店内编码。批量导入时，错误 ISBN 显示警告，确认后新增图书的 ISBN 留空；按店内编码更新已有图书时保留已有有效 ISBN，原输入记入模板的备注。空 ISBN 的更新行仍按模板清空已有 ISBN；若要保留，请填写原 ISBN。真正的冲突或错误仍会阻止整批写入。
2. 在“字典管理”维护供应商、分类和收款方式。停用不会删除历史单据。
3. 在“设置 → 数据安全”选择第二备份位置（推荐 U 盘或另一块硬盘），保存后创建一次备份并点击“验证最近一次备份”。

## 日常营业

- **进货**：采购入库 → 选供应商 / 日期 / 图书 → 保存草稿 → 核对数量与折扣 → 确认入库。只有复核才增加库存。
- **收银**：销售开单 → 扫码、输入店内编码 / ISBN / 书名 / 作者，或 F3 选书 → 核对折扣 → 选择收款方式；现金填写实收并核对找零 → 确认结账。结账后可打印小票，工具栏“重打上一张”可补打；纸宽在设置页选择 58 / 80 mm。
- **挂单**：F5 保存、F6 取回。挂单不改变库存，结账时会重新检查库存。
- **退货**：单据中心找到原单发起退货。退款按原成交快照，不允许超量退货。
- **盘点**：库存管理 → 盘点单，按货架位生成计划数，填写实盘数后确认，系统只对差异生成 ADJUSTMENT 流水。盘点期间若发生销售/采购，需重新盘点。少量差异也可用“库存调整”并填写原因。
- **查账**：报表与导出按业务日期查询。销售退货按退货日期扣减净销售，不改写原销售月份的销售合计。

## 关店与备份

每天正常退出程序会生成备份；每日首次启动也会检查，当天最新备份损坏时会尝试重新生成，启动备份失败会给出警告。设置页可调整新格式自动备份的保留份数（3–120，默认 14）。自动清理只处理系统新生成的自动备份；旧格式和手工备份不会自动清理，请在确认安全后自行管理空间。状态栏按当前自动备份目录内的 `bookstore_*.db` 文件显示最近备份；文件被删除或目录更换后，不会仅凭历史时间误报成功，手动选择其他位置的备份不会计入该状态。状态显示不代替“验证最近一次备份”。超过 3 天提醒，超过 7 天红色警告。第二份备份失败时不要只看到“主备份成功”就拔盘，请先检查提示。

恢复：备份与恢复 → 选择备份 → 确认。系统先校验、保存恢复前快照，再替换并升级；失败自动回滚。恢复期间不能取消，完成后自动重启。

## 报表与打印

普通报表可导出 `.xlsx`、旧版 `.xls` 或 UTF-8 `.csv`；月报支持 `.xlsx` / `.xls`。工作簿包含打印页边距、重复表头和页码，不需要安装 Excel。CSV 为纯文本，不保留多 Sheet / 打印版式，且对公式开头字符做防注入处理。销售 / 采购月报包含整月每日明细。参考成本是经营估算，不是会计成本。

### 图书标签（每页一张）

在“图书资料”点击“打印标签”，可反复点击“添加图书”组成批次，填写每种 1–100 张（单次最多 100 种、1000 张）。选择 50×30 或 60×40 mm，确认后选择打印机；请先在打印机驱动中设置相同尺寸和横向宽度，先试打一张并用销售扫码框核对。标签显示书名、当前售价和店内编码 Code 128，不会生成 ISBN。只支持可打印半角英文、数字和符号；编码太长放不下或打印区域太小时会拒绝打印，请改用更宽的标签或更高分辨率打印机。长书名可能省略，打印前请核对。若图书资料在添加后发生变化，请移除并重新添加。打印不修改库存。

此功能需要 Windows 打印机驱动支持自定义标签尺寸；打印机硬边距、标签纸和扫码枪兼容性需在目标设备上试验，不支持 A4 多标签排版。

## 遇到问题

在“设置 → 导出诊断包”生成 ZIP 发给维护人员。诊断包包含日志、版本、系统 / DPI / 字体信息，不包含数据库。错误提示中的编号可在日志中定位。常见安装、显示、扫码和 Excel 问题见 [FAQ](FAQ.md)。
