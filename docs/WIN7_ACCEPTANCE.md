# Windows 7 验收与兼容性说明

本项目目标环境为 **Windows 7 SP1（x86 / x64）+ .NET Framework 4.8 + WinForms x86 + SQLite 离线**。
Windows CI（windows-2022）可以证明代码、依赖、安装器与界面布局在 Windows 上可构建 / 可运行，但**不能替代 Win7 实机验收**。

## 已自动验证（每次 PR / push）

- `msbuild` Debug / Release x86；生产包不包含测试 / UiTools。
- 25 个 MSTest（net48/x86）：迁移安全、备份、ISBN 可选 / 错误 ISBN 不阻断建档、批量导入、盘点、xls / CSV、小票快照等。
- Release 目录 `--self-test` 冒烟：schema 版本、FULL synchronous、备份可校验。
- UiTools 全量业务 / UI 自检与多分辨率截图（1024×768、1366×768、1800×900 等）。
- 离线安装器：Inno Setup 6.7.3 与 .NET 4.8 离线包均做 SHA-256 固定 + Authenticode 校验；无证书时产物标记 UNSIGNED。

## 仍需在 Win7 实机人工验收

1. **系统 / 运行时**：Win7 SP1 x86 与 x64 各一台；安装 .NET 4.8 离线包；确认程序以 x86 运行。
2. **字体**：确认系统安装宋体（SimSun）；界面中文不出现方框 / 缺字；高 DPI 下按钮 / 表格不截断。
3. **小屏**：1024×768 下首页、销售、采购、图书、库存、报表、设置、备份页底部操作栏可见，无横向遮挡。
4. **Office / WPS 导出**：用 Excel 2007+ 与 WPS 打开 `.xlsx`、`.xls`、`.csv`；确认中文不乱码、金额 / 数量列正确、CSV 公式开头字符不被执行。
5. **小票打印**：58 mm 与 80 mm 热敏纸各打印一张；确认结账后打印、重打上一张、多页续打与纸宽设置一致。
6. **备份 / 恢复**：主备份 + U 盘 / 另一块硬盘第二备份；断开第二备份地点后状态栏 / 弹窗提示；用备份恢复后库存 / 流水 / 历史快照一致。
7. **性能目标（待实测）**：冷启动 < 8 s、切页 < 300 ms、月报导出 < 10 s；低配模式下动画关闭、后台任务不阻塞 UI。
8. **签名**：若配置 `BOOKDESK_SIGNING_CERT` / `BOOKDESK_SIGNING_PASSWORD`，确认安装包与主程序 Authenticode 签名有效；未配置时只能作为 UNSIGNED 测试包。
