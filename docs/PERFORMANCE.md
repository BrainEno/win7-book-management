# 低配 Win7 性能基线

目标环境：2 GB RAM、双核、机械硬盘、Win7 SP1、Aero 关闭、1024×768。目标值（待实机测量，不是已达成结果）：冷启动 < 8 秒，常用页面切换 < 300 ms，一个月数据的月报导出 < 10 秒且全程有进度 / 可取消。

测量：同一快照、同一数据量，冷启动重启系统后测 5 次取中位数；页面切换测工作台→销售→采购→报表；月报分别测空月、普通月、峰值月。记录安装包版本 / SHA-256、NGEN 是否完成、低配模式、数据行数和耗时。

已实现的降本措施：自动 / 手动低配模式关闭动画与高质量文字渲染；安装时 NGEN；备份 / 恢复 / Excel 在后台执行；导出原子发布；搜索结果上限配合分页提示。实机结果请在发布 PR 中附上，未测量前不关闭性能验收项。
