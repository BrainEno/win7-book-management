# 常见问题

**Win7 安装 .NET 4.8 失败？** 先确认 SP1，并安装对应架构的 KB4490628 与 KB4474419 后重启。安装器会显示中文提示和日志目录 `%ProgramData%\Win7BookManagement\logs\dotnet48`。机械盘安装可能需要 10–20 分钟，请勿断电。

**屏幕放不下 / 字被裁？** 主窗口会按工作区夹取并在小屏折叠侧栏。请使用 100%–150% 系统缩放并更新显卡驱动；仍有问题时导出诊断包，附上分辨率与缩放比例。

**备份放在哪里？** 默认主备份在 `%ProgramData%\Win7BookManagement\backup`，与数据库同盘不能防硬盘损坏。请在设置页配置第二位置或使用 U 盘。不要复制运行中的 `.db`、`-wal`、`-shm` 来代替备份。

**第二份备份失败？** 检查 U 盘是否插好、是否只读、空间是否足够、网络共享是否断开。主备份仍会保留，状态会显示警告。修复后重新创建并验证备份。

**旧 Office 打不开 .xlsx？** 使用 Office 2007+、Office 2003 兼容包或 WPS。导出本身不需要 Excel。旧软件对复杂月报版式支持可能不同，发布前应按烟测清单实机打开验证。

**扫码枪不能用？** 将扫码枪设置为键盘楔形模式，后缀 Enter，编码与图书 ISBN / 店内编码一致；在销售扫码框或采购明细表测试。无 ISBN 商品可用店内编码。

**ISBN 填错或没有 ISBN 怎么办？** 新建 / 编辑图书时 ISBN 可留空。若填入了格式或校验位不正确的 ISBN，保存时可选择“清空 ISBN 并继续保存”；原始输入会记入备注，系统继续使用自动生成的店内编码，不会生成假 ISBN。

**界面动画卡顿？** 设置 → 渲染性能选择“低配模式：始终开启”。备份和导出在后台执行；取消导出不会覆盖已有文件。

**恢复后为什么要重启？** 重启会重新加载所有页面和数据库连接，避免旧页面缓存继续显示恢复前数据。

**批量导入时 ISBN 填错怎么办？** 预览会显示警告：确认导入后，新图书的 ISBN 留空，更新已有图书时保留已有有效 ISBN，原输入记入备注；不生成假 ISBN。书名缺失、重复及编码冲突仍阻止整批导入。空 ISBN 的更新行会清空已有 ISBN，如需保留请填写原 ISBN。

**标签打不出来或扫不出？** 在打印机驱动和程序中选择一致的 50×30 / 60×40 mm 标签；先试打一张，用支持 Code 128 的扫码枪测试。编码过长、包含中文等非半角字符或打印区域太小时，程序会提示并拒绝打印。标签上的条码是店内编码，不是 ISBN；低分辨率或纸张边距过大时请换更宽标签或更高分辨率打印机。

**旧备份为什么没被自动删除？** 安全起见，滚动清理仅删除新格式 `bookstore_auto_日期_唯一编号.db` 自动备份；升级前的旧格式和手工文件不会被清理。请先确认其他位置有可用备份，再自行整理旧文件。启动时会校验当天最新备份，损坏则尝试重新创建；状态显示文件存在并不代替定期点击“验证最近一次备份”。
